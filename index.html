Lecture 1 · Introduction to Data Structures and Data Types

Which sentence best describes a data structure?

Model answerA way to organize data so we can access and modify it efficiently.

What does a Data Type represent, and what does a Data Structure represent?

Model answerA data type is the nature of the data; a data structure is a grouping of similar or different types into one unit. Careful: there is a reversed option with the same wording that trips people up.

What does a data type define?

Model answerThe values you may use and the operations allowed on them. Insert/remove ordering is Stack and Queue talk, not the definition of a data type.

Lecture 2 · The Stack and the LIFO Principle

Evaluate the postfix expression: 3 8 2 - * 4 +

Model answer22. Stack steps: push 3, 8, 2; '-' pops 8 and 2 giving 6; '*' pops 3 and 6 giving 18; push 4; '+' pops 18 and 4 giving 22. A real Quiz 1 (Fall 2026) question.

Convert A/B-(C+D) to postfix.

Model answerAB/CD+-. Parentheses first: C+D becomes CD+, then A/B becomes AB/, and the subtraction comes last. Also from Quiz 1.

Why is the stack the right choice for function calls?

Model answerBecause the last function called must finish and return first, which is exactly LIFO behavior.

Lecture 3 · The Queue and the FIFO Principle

Trace enqueue(5), enqueue(3), dequeue(), enqueue(7) on an empty queue. What is at the front?

Model answer3. The 5 entered first and left with the dequeue, so 3 is at the front with 7 behind it. Same queue-question pattern as Quiz 1.

What is the core difference between a Simple and a Circular Queue?

Model answerThe circular one wraps the pointers so it reuses freed slots after deletions, while the simple one ends up apparently full even though free slots remain.

What is a Deque?

Model answerA queue that allows insertion and deletion at both ends, not one end per operation.

Lecture 4 · Memory and Pointers in C++

int x = 5; int *p = &x; *p = 10; print x. What is the output?

Model answer10. The dereference modified x itself through its address.

Why pass by reference to a function that should modify its input?

Model answerPassing by value makes a copy, so the change is lost. By reference the function works directly on the original variable.

What is the difference between a pointer and a reference?

Model answerA reference is an alias for one variable for its whole life and cannot be null; a pointer is an independent variable that can be reassigned and can point to null.

Lecture 5 · Linked Lists

When is a linked list better than an array?

Model answerWhen the size changes often or insertions and deletions are frequent, since it needs no shifting of elements and no fixed size up front.

If the head is lost, what happens?

Model answerThe whole list is lost: there is no way to reach any node, because the only access is walking from the head.

What does a doubly linked list add over a singly linked one?

Model answerA prev pointer per node, so you can walk backwards and delete the node you are standing on without holding the one before it.

Lecture 5 · Boolean Algebra Theorems and Proofs

Show that A + BC = (A + B)(A + C).

Model answerFrom the right: (A+B)(A+C) = A + AC + AB + BC = A(1+C) + AB + BC = A + AB + BC = A(1+B) + BC = A + BC. Real Quiz 2 question 2(a), worth 10 marks.

Simplify (A + B)(A + B).

Model answerA. (A+B)(A+B) = AA + AB + AB = A + AB = A(1+B) = A. Question 2(a) from the other Quiz 2 version.

Simplify x + x′y.

Lecture 6 · Complement of a Function and Standard Forms (Minterms and Maxterms)

Write F = xy + x′z as a Product of Maxterms.

Model answerΠ(0,2,4,5). Distribute: (xy+x′)(xy+z) = (x+x′)(y+x′)(x+z)(y+z), drop (x+x′), and add the missing variables to each OR term. Solved step by step in the Section 4 slides.

Lecture 7 · Canonical Forms and Standard Gates

Model answerXNOR. A real MCQ from the other Quiz 2 version. (XOR outputs 1 when the inputs differ.)

Lecture 8 · Gate-Level Minimization and the Karnaugh Map

Simplify with a Karnaugh map: F(A,B,C) = Σ(3,4,6,7).

Model answerF = AB + BC + AC′. Groups: (3,7) gives BC, (6,7) gives AB, and (4,6) gives AC′. Real Quiz 2 question 3 (5 marks).

Why is the map ordered by Gray code, not plain binary?

Model answerSo physical adjacency matches logical adjacency: every two neighboring cells differ in exactly one variable, so any adjacent grouping eliminates a variable.

Simplify using Quine-McCluskey: F(A,B,C,D) = Σ(0,1,2,6,8,9,10).

Model answerF = A′CD′ + B′D′ + B′C′. The model answer to Quiz 2 question 4 (10 marks): combine minterms differing in one bit and cover with the essential prime implicants.

Section 1 · Numbering Systems and Conversions

Convert 44.5625 (decimal) to binary, describing the method.

Model answer101100.1001 in binary. Integer part: repeated division by 2, reading the remainders upward (44 becomes 101100). Fraction: repeated multiplication by 2, reading the integer parts downward (0.5625 becomes .1001).

Convert 431.1875 (decimal) to hexadecimal.

Model answer1AF.3 in hex. 431/16 leaves remainders 15 (F), 10 (A), 1 read upward; the fraction 0.1875 x 16 = 3.0 gives .3.

Section 2 · Octal/Hex Conversions and Logic Gates

Convert 1011010111 (binary) to octal, stating the grouping rule.

Model answerGroup the bits in threes starting from the right: 001 011 010 111 becomes (1327) octal.

Convert 1F0C (hex) to octal.

Model answerUse binary as an intermediary: each hex digit to 4 bits (0001 1111 0000 1100), then regroup in threes from the right: (17414) octal.

Section 3 · Boolean Simplification, Practical Session

Prove (x + y)(x + y′) = x using the postulates.

Model answerExpand: x.x + x.y′ + y.x + y.y′ = x + xy′ + yx + 0 = x + yx + xy′ = x(1 + y + y′) = x(1+1) = x.

Prove the consensus theorem xy + x′z + yz = xy + x′z.

Model answeryz = yz(x + x′) = xyz + x′yz; then xy(1 + z) + x′z(1 + y) = xy + x′z. The term yz is redundant: xyz is absorbed by xy and x′yz is absorbed by x′z.

Section 4 · Complement, Minterms and Maxterms (Lecture 6 Lab)

Express F = A + B′C as a sum of minterms, showing the expansion trick.

Model answerMultiply A by (B + B′) and (C + C′) to add the missing variables: ABC + ABC′ + AB′C + AB′C′ + A′B′C, so F = Σ(1, 4, 5, 6, 7).

Given F = Σ(1, 3, 6, 7), write F′ and then F as a product of maxterms.

Model answerF′ takes the missing minterms: F′ = Σ(0, 2, 4, 5). Then F = Π(0, 2, 4, 5) by interchanging the symbols and listing those missing numbers.

Model answerBecause the predictive parser would loop forever: every time it tries A it calls A again without consuming any input.

Lecture 8 · FIRST, FOLLOW and Predictive LL(1) Parsing

Given S ← AB, A ← xB | ε, B ← yA, compute FIRST and FOLLOW.

Model answerFIRST(S) = {x, y} because A can be ε so we take FIRST(B). FIRST(A) = {x, ε}, FIRST(B) = {y}. FOLLOW(S) = {$}, FOLLOW(A) = {x, y, $}, FOLLOW(B) = {x, y, $}. Exactly the Quiz 2 (Fall 2025) question; the solved paper is in the folder.

What condition makes a grammar not LL(1)?

Model answerA table cell holding more than one rule: alternatives of the same nonterminal whose FIRSTs intersect, or ε in a FIRST with FOLLOW intersecting the other alternatives' FIRSTs.
